# 管理表格与运行端列表规范

配套主技能见 [../SKILL.md](../SKILL.md)，视觉规范见 [frontend-ui-standard](../../frontend-ui-standard/SKILL.md)。本页提取已有数据中心、应用中心表格约定；工程路径以仓库根目录为基准。

## 复用与布局

- 实现参考 `os-front/src/views/system/user/index.vue`；复用 `os-front/src/components/os-table-page/OsTablePage.vue` 和 `os-front/src/composables/useOsTablePage.ts`，不重建搜索、序号、分页、列设置或固定列协议。
- 主列表采用搜索卡片与表格卡片，占满内容区，表体内部滚动，分页在卡片底部；已有菜单标题的页面不重复添加大标题和介绍。
- 内嵌字段、关系、索引、版本、发布记录与应用引用列表继续用 OsTablePage，去掉重复外层业务卡片；单元格插槽保留已有编辑、配置和排序行为。
- 页面整体边距继承 BasicLayout，业务页与内嵌看板不叠加整页 padding。对象设计器占满剩余内容区，顶部操作、页签、表头保持可见；增长的字段在表体内滚动。
- 无代码管理表格的适配样式使用 `os-front/src/views/nocode/management-tables.css` 中的限定类，保持公共组件与系统管理兼容。
- 分类列表沿用左树右表：分类树独立获取，不受右表分页限制；切换分类回到第一页，保留其他查询条件，重置同时清除分类。

## 查询与工具栏

- 基础查询使用带可见标签的 `a-form layout="inline"`；同类控件宽度保持一致。查询为带搜索图标的主按钮，重置带刷新图标；回车和按钮走同一查询入口，查询从第一页开始。
- 管理接口的次要条件放静态 `advancedSearch` 插槽，不向未支持组合条件的接口传入动态协议；运行端复用 OsDynamicSearch 的 AND/OR 条件和收藏。
- 临时高级条件显示摘要标签，支持查看、编辑、清除；清除先通知调用方移除高级条件再查询。取消编辑保留已生效条件，页面重载不恢复未收藏的临时条件。
- 查询中的引用、目录多选使用 SelectionField 紧凑模式折叠为部分名称与“+N 项”，支持悬停或键盘查看；仅折叠呈现，不截断提交值。
- 标题居左，新增、刷新、导入、列设置位于右侧；新增为主按钮，其他动作根据实际能力和权限启用。

## 列、分页与滚动

- 默认沿用底座 `middle` 密度、无外边框、居中表头和单元格；确需按数据类型调整的列显式配置 `align`。长文本提供省略与完整提示，时间复用格式化函数。
- 序号由 OsTablePage 注入，不重复声明。列具有稳定 key、合理默认宽度；管理列表启用 resizable 和列设置，每种列表使用独立持久化键。
- 运行端业务列严格按发布视图 `fieldIds` 及顺序生成，不自动增加记录编号；个人列设置只能控制当前视图已有列的显隐。
- 操作列固定在右侧，沿用图标加文字链接、分隔符、危险色及原有确认和权限规则。应用已引用对象的纯图标操作保留功能提示和无障碍名称。
- 分页默认每页 10 条，选项沿用 10/20/50/100，并显示总条数；切换条数回到第一页，序号跨页连续。运行端尊重已发布视图的自定义条数。无代码接口使用 `pageNo`，不与底座 `pageNum` 混用。
- 已由服务端分页且会插入展开子项、编辑行的列表，可按实际需要启用 `serverPagination`，避免表格二次截取；附加行不增加服务端总数，不改变其他列表默认行为。
- 表格只在自身容器横向滚动，不撑宽整页。对象数据网格的序号和记录 ID 可固定在左侧，操作列固定在右侧；使用组件固定列能力，不另写固定像素定位。
- 视图列设置和查询收藏按用户、应用、对象、视图隔离；导出与列表使用相同的已生效条件。批量删除保持默认关闭及逐条版本、权限校验。

## 验证

按实际改动检查常规和窄视口、横纵滚动、固定列、查询与重置、分页与条数切换、权限显隐和行内编辑；只操作可识别夹具，保留用户现有数据。前端门禁与真实运行要求见主技能。
